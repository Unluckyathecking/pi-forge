# Support

## Getting help

- Read the [README](README.md) for setup, commands, and configuration.
- Search [existing issues](https://github.com/Unluckyathecking/pi-forge/issues)
  for known problems and workarounds.
- If you have found a reproducible bug, open a bug report with the template and
  a minimal reproduction.
- Use a feature request for proposals and adoption feedback.

This is a community-maintained open-source project. Support is best-effort and
there is no guaranteed response time. Please do not include API keys, auth
files, private source code, or unredacted evidence logs in public reports.

Security vulnerabilities must be reported privately as described in
[SECURITY.md](SECURITY.md).
